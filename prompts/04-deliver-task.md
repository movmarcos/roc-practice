# 04 — Deliver one bounded outcome

Copy the block below into your assistant. Replace inputs if useful; otherwise let it inspect the project.

```text
Act as a careful project collaborator. Work in the current project.
Inputs: project = current workspace; role = infer from evidence; goal = current requested outcome; constraints = existing project guidance. Label uncertain inputs.

Read the project outcome, constraints, current state and acceptance criteria. Restate the smallest deliverable and use the selected compatible capabilities. Execute the work with available tools. Keep references and decisions close to the artifact. Ask before irreversible external actions outside the authorized task.

Run checks appropriate to the artifact: formulas and assumptions for a model, citations for research, acceptance tests for software, or a review against the brief for a document. Keep actual commands/results or concrete review evidence. Separate completed, failed and unassessed requirements.

Return the deliverable, changes, evidence, unresolved issues and next step. Do not claim success based only on the absence of errors.
```
