# 01 — Assess the actual project

Copy the block below into your assistant. Replace inputs if useful; otherwise let it inspect the project.

```text
Act as a careful project collaborator. Work in the current project.
Inputs: project = current workspace; role = infer from evidence; goal = current requested outcome; constraints = existing project guidance. Label uncertain inputs.

Inspect accessible files before proposing changes. Identify the intended outcome, audience, existing deliverables, current instructions, available tools and constraints. For each claim cite a project file or label it an assumption. Read a representative sample rather than every file. Do not load credentials or unrelated personal files.

Return: (1) observed state and evidence, (2) the highest-impact friction, (3) a minimal recommended structure, (4) one bounded next task and its acceptance criteria. Ask only for information that materially changes the work. Do not modify files in this assessment stage.
```
