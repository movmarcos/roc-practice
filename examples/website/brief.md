# Common Ground — fixed website brief

Create a polished website for the fictional community workshop brand Common Ground. Use the exact facts in `content.json`. Audience: adults choosing a practical workshop. Use plain HTML, CSS and JavaScript, with no build dependencies or remote services. Make your own visual choices within a warm, professional brand. Deliver runnable files and launch instructions.

Acceptance criteria (same in all conditions):

1. Brand, tagline and all six supplied events appear with accurate titles, categories, dates and durations.
2. Layout is readable at 375px and 1440px widths without horizontal scrolling.
3. A category filter correctly limits events, including an All option.
4. A search field supports a no-results state and clear/reset action.
5. Each event exposes its complete description and booking action.
6. Navigation and interactive elements work with keyboard alone and expose visible focus.
7. Use semantic headings, labelled inputs and informative button/link names.
8. Booking form requires an event, name and valid email, with understandable validation feedback.
9. Successful submission clearly says it is a local demonstration; no data is transmitted or real booking made.
10. Provide instructions to run, check and update events, plus evidence of checks actually performed.
